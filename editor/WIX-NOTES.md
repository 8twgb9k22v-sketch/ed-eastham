## 1. Layout (top bar, left toolbar, canvas, right panel)

**Classic top bar**, Wix’s documented left-to-right order: Page dropdown → Desktop/Mobile → Site → Settings → Dev Mode → Hire a Professional → Help → Upgrade → Undo → Redo → Zoom Out → Tools → Search → Save → Preview → Publish. Site includes history; Tools toggles toolbar, rulers, gridlines and snapping. [Menus](https://support.wix.com/en/article/wix-editor-using-the-editor-menus)

**Classic left**, documented order: Add Elements (type tabs) → Add Section (presets/blank) → Pages & Menu (add/delete/manage pages) → Site Design (colours/text/backgrounds/transitions) → Add Apps (App Market) → Media (uploads/libraries). Extra icons depend on installed features. The canvas holds the page; Tools → Toolbar exposes layout controls. [Menus](https://support.wix.com/en/article/wix-editor-using-the-editor-menus) [Toolbar](https://support.wix.com/en/article/wix-editor-using-the-editor-toolbar-to-adjust-elements)

**Studio top:** Wix Studio/site tools → page navigation → Desktop/Tablet/Mobile breakpoints → Undo → Redo → Preview → Publish; complete intervening control order (unconfirmed). **Left**, tutorial sequence: Add Elements (Quick Add, Assets, sections, containers) → Layers (hierarchy) → Pages (page settings) → Global Sections → Site Styles → App Market → CMS → code. Media is also available; its position (unconfirmed). [Tour](https://www.wix.com/studio/academy/tutorials/how-to-get-started-in-the-wix-studio-editor) [Images](https://support.wix.com/en/article/studio-editor-adding-creating-and-uploading-images)

**Panels:** click left icons to open; Studio’s Open Inspector arrow opens the right panel for selected-element properties. Side panels toggle with Cmd/Ctrl+.; Inspector with Cmd/Ctrl+I. Classic Hide Controls collapses menus/tools. Movable panel docking and universal close-button behaviour (unconfirmed). [Inspector](https://support.wix.com/en/article/studio-editor-using-the-inspector-panel) [Shortcuts](https://support.wix.com/en/article/studio-editor-keyboard-shortcuts) [Menus](https://support.wix.com/en/article/wix-editor-using-the-editor-menus)

## 2. Selection and editing behaviours

1. **Hover:** Studio Layers hover highlights the corresponding canvas element; direct canvas hover outlines/labels in both editors (unconfirmed). [Layers](https://support.wix.com/en/article/studio-editor-working-with-layers)
2. **Click:** selects an element; Classic shows a floating action toolbar above/below it; Studio supports parent-first or child-first selection. [Selection](https://support.wix.com/en/article/wix-harmony-editor-the-difference-between-wix-editor-and-wix-harmony) [Layers](https://support.wix.com/en/article/studio-editor-working-with-layers)
3. **Text:** select → Edit Text → type/paste directly in the text element; Classic also documents double-click access. [Text](https://support.wix.com/en/article/wix-editor-adding-and-editing-text) [Formatting](https://support.wix.com/en/article/wix-editor-changing-your-text-font) [Studio-text](https://support.wix.com/en/article/studio-editor-adding-and-customizing-text)
4. **Text toolbar:** Classic Text Settings offers font, size, colour, bold/italic/underline, alignment and spacing, including highlighted words; Studio documents formatting in Inspector. [Formatting](https://support.wix.com/en/article/wix-editor-changing-your-text-font) [Studio-text](https://support.wix.com/en/article/studio-editor-adding-and-customizing-text)
5. **Images:** select → Change Image → choose/upload → Choose Image in Classic; Studio Change Image also opens Media Manager. Site Files, Visitor Uploads, My Boards, Trash and stock libraries sit alongside search, folders, filters and file details. [Replacement](https://support.wix.com/en/article/wix-editor-generating-page-sections-with-ai) [Images](https://support.wix.com/en/article/studio-editor-adding-creating-and-uploading-images) [Media](https://support.wix.com/en/article/wix-media-about-the-media-manager)
6. **Drag/resize:** Classic drags elements freely, uses stretch handles and precise W/H/X/Y fields; Studio Layers reorders within a parent, while Shift+Resize preserves proportions. Portfolio adaptation: reorder whole works inside their category, keeping captions attached. [Elements](https://support.wix.com/en/article/wix-editor-working-with-elements) [Toolbar](https://support.wix.com/en/article/wix-editor-using-the-editor-toolbar-to-adjust-elements) [Layers](https://support.wix.com/en/article/studio-editor-working-with-layers) [Shortcuts](https://support.wix.com/en/article/studio-editor-keyboard-shortcuts)

## 3. Design/Theme panel

Classic Site Design → Change Theme → Colors/Text changes palettes and heading/paragraph styles; themed elements update together, with backgrounds/transitions also available. Studio calls this **Site Styles**, synchronizing connected font/colour styles. “Theme Manager” is not the name confirmed here. Portfolio adaptation: Background, Text, Accent, Typeface and Logo controls; logo replacement uses media selection. [Theme](https://support.wix.com/en/article/wix-editor-customizing-your-sites-theme-and-design) [Tour](https://www.wix.com/studio/academy/tutorials/how-to-get-started-in-the-wix-studio-editor)

## 4. Save, Publish, Preview, Undo/Redo, Mobile switch

Classic autosaves regularly after the first manual Save; Preview also saves and exits through Back to Editor. Studio autosaves every change, shows a saved indication, and offers Wix Studio → Site → Save; Preview exits through Edit Site. In both, Publish makes edits live: saved-but-unpublished changes are distinct from unsaved changes; exact “unpublished changes” badge wording (unconfirmed). Undo/Redo reverse/reapply actions. Classic switches Desktop/Mobile; Studio edits Desktop/Tablet/Mobile breakpoints and previews adjustable widths. [Classic-save](https://support.wix.com/en/article/wix-editor-saving-previewing-and-publishing-your-site) [Studio-save](https://support.wix.com/en/article/studio-editor-saving-previewing-and-publishing-your-site) [Menus](https://support.wix.com/en/article/wix-editor-using-the-editor-menus) [Tour](https://www.wix.com/studio/academy/tutorials/how-to-get-started-in-the-wix-studio-editor)

## 5. Keyboard shortcuts and context menus

Use Cmd on Mac instead of Ctrl: Z undo, Y redo (Studio also Cmd+Shift+Z), S save, C/V copy/paste, D duplicate; B/I/U format text. Classic: Cmd+P preview, Cmd+J mobile switch, Shift+F hide controls, Escape cancels transforms. Studio: Cmd+Option+P preview, Escape deselects. Right-click is contextual: Classic Copy/Paste and Arrange layer actions; Studio Layers offers copying/reordering via right-click or More Actions. [Classic-keys](https://support.wix.com/en/article/wix-editor-keyboard-shortcuts-in-the-editor) [Studio-keys](https://support.wix.com/en/article/studio-editor-keyboard-shortcuts) [Elements](https://support.wix.com/en/article/wix-editor-working-with-elements) [Toolbar](https://support.wix.com/en/article/wix-editor-using-the-editor-toolbar-to-adjust-elements) [Layers](https://support.wix.com/en/article/studio-editor-working-with-layers)

## 6. "Copy this" list

Portfolio recommendations, ordered by value; adapted from [editing](https://support.wix.com/en/article/wix-editor-adding-and-editing-text), [media](https://support.wix.com/en/article/wix-media-about-the-media-manager), [saving](https://support.wix.com/en/article/studio-editor-saving-previewing-and-publishing-your-site) and [layers](https://support.wix.com/en/article/studio-editor-working-with-layers).

1. Edit work titles and captions inline.
2. Replace work pictures through Change Image.
3. Save drafts without publishing.
4. Show Saved and Unpublished changes separately.
5. Make Publish an explicit action.
6. Provide Undo and Redo for every edit.
7. Preview without editing overlays.
8. Reorder works within their category by dragging.
9. Edit category titles and intros in place.
10. Edit page paragraphs and tagline identically.
11. Highlight editable targets on hover.
12. Anchor contextual actions beside selection.
13. Group colours, typeface and logo under Design.
14. Switch between desktop and mobile previews.
15. Preserve selection when closing panels.
