# Ed Eastham

Portfolio site for the artist Ed Eastham. Static, no build step.

- `index.html` is the whole site.
- `content/site.json` holds every word, work and setting. Edit it directly or through `/admin`.
- `assets/work/` holds the pictures.
- `admin/` is the Decap CMS editing screen (needs Netlify Identity + Git Gateway).
- `HOW-TO-EDIT.md` is the guide for the owner.
